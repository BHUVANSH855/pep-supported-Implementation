## Evidence discipline

PyPI release pages are used for published artifact names, release metadata,
classifiers and project-provided descriptions.

Project source/documentation is used for implementation-level behavior.

Standards documents are used for normative semantics.

Where the repository draws an inference from these sources, the inference is
identified as such rather than presented as a source statement.
